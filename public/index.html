API anahtarları

Account ID cüzdan adresi değildir. Farklı hesap seçmek için QFEX hesap UUID'sini kullanın.

Anahtarlar bu bilgisayarda Windows kullanıcı hesabınıza bağlı şifrelemeyle saklanır. Tarayıcı depolamasına yazılmaz.

Hesap bağlı değil

Bu sürüm yalnızca hesap verilerini okur; emir göndermez. Bağlantıyı kaldırmak yerel kaydı siler. Anahtarı iptal etmek için QFEX ayarlarını kullanın.

QFEX'te anahtar oluşturma

Developer → Generate public and secret API keys → isim: Volume Desk → kullanacağınız hesap.

View balance, View positions ve View orders açık olsun. Şimdilik Execute orders ve Deposit and withdraw kapalı kalsın. Builder code oluşturmanız gerekmiyor.

SET TWAP TIMING

Açılış ve kapanış

Süre ilk alt emirden son alt emre kadardır. 1 dk / 30 sn: 0, 30 ve 60. saniyelerde üç alt emir. QFEX TWAP maliyeti taker üzerinden hesaplanır.

Döngü zamanlaması

Bekleme kapalıysa operation sleep uygulanmaz. Cycle sleep, kapanış tamamlandıktan sonraki aradır.
